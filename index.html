What's inside

One install command. Eight apps. All writing to your pod as JSON-LD, so any other pod-aware tool can read them.

  • plaza

    Group chat — Slack-shaped UI, Solid-native data. Cross-pod by default once you open it to visitors.

  • chat

    1:1 direct messages across Solid pods. Nostr-encrypted, live delivery.

  • vellum

    Markdown editor. Shared specs, design docs, meeting notes — all on the team's pods.

  • plume

    Team blog. Announcements, weekly updates, decision logs. Each post is a resource other apps can read.

  • taskify

    Task tracking and dashboard. Who's doing what, what's done, where we are.

  • explorer

    File browser with per-row ACL. See and share what's on the pod with keyboard nav and trash-undo.

  • hub

    Multi-app workspace shell. Opens any pod resource in the right app.

  • chrome

    Desktop-style window manager. For teammates who want everything in a launcher.

Why pods, not platforms

You own your messages.

Slack owns your messages. Notion owns your docs. Linear owns your tasks. When you outgrow the price, the integration, or the company itself, your team's history is locked behind their export tools.

solid-teams flips that. Each member's data is on their own Solid pod. Leaving the team doesn't lose their work. Closing the team doesn't delete the conversation.

Federated by default.

No Slack Connect, no Microsoft Teams Federation, no shared-workspace setup. Pods talk to pods natively. A teammate at one pod and a teammate at another are in the same room, no bridge bot required.

The protocol is the network effect.

Open source. Auditable.

AGPL-3.0. Every app is a small repo you can read, fork, or replace. No closed-source server you have to trust. No tracking pixels. No telemetry. No "AI training data" small print.

For enterprises.

Built for teams that want to own their data, run on their own infrastructure, and avoid vendor lock-in. If those are your requirements, this is the substrate.

What's not here yet: SSO, audit logs, retention policies, SOC2. If those are deal-breakers today, watch this space — and feel free to open an issue with your specific need.

Install in 2 minutes

  1. Make sure you have Node 18+.

  2. Install jspod and solid-teams:

    npm i -g jspod solid-teams

  3. Start a pod (or point at one you already run):

    jspod start --idp

  4. Install the team workspace into it:

    solid-teams install

  5. Open http://localhost:4443/public/apps/plaza/ and you're in.

Or run against any existing Solid pod: solid-teams install --pod https://your-team.example
